
# 🐍 snake-game

## Objetivo do Jogo
SNAKE GAME! Controle a cobrinha, colete as frutinhas e tente alcançar a maior pontuação possível sem bater nas paredes ou no próprio corpo.

##  Regras e Como Jogar
* **Movimentação:** Utilize as setas direcionais do teclado ⬆️ ⬇️ ⬅️ ➡️ para controlar a cobrinha.
* **Início do jogo:** Pressione `ENTER` no menu inicial para começar.
* **Pontuação:** Cada frutinha azul coletada aumenta a pontuação em +1 ponto.
* **Crescimento:** Ao coletar uma frutinha, a cobrinha aumenta de tamanho.
* **Nova fruta:** Depois que uma fruta é coletada, outra aparece aleatoriamente no tabuleiro.
* **Fim de jogo:** A partida termina quando a cobrinha bate em uma das paredes ou em seu próprio corpo.
* **Reiniciar:** Após o Game Over, pressione `ENTER` para começar uma nova partida.

## Tecnologias Utilizadas
Para o desenvolvimento deste projeto, foram utilizadas as seguintes tecnologias:
* **HTML5:** Utilizado para estruturar a página e criar o elemento `<canvas>` onde o jogo é exibido.
* **CSS3:** Utilizado para estilizar a página, definir o fundo, posicionar o jogo e configurar a aparência do `<canvas>`.
* **JavaScript:** Utilizado para desenvolver toda a lógica do jogo, como movimentação da cobra, criação das frutas, pontuação, colisões, Game Over e reinício.
